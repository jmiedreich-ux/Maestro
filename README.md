# Maestro

Maestro is a project-neutral system for controlled AI-assisted engineering work. It combines durable local coordination, repository-aware project boundaries, agent roles, evidence handling, and the Reporting and Command Interface.

The repository contains working foundations, but stored records and isolated components do not by themselves prove complete end-to-end operation. Verify current behavior against the code before describing a capability as complete.
