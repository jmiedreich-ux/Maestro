# Maestro development handoff rules

`ai/handoffs/current.md` is a compact pointer to the current scope, checkpoint, next action and unresolved blockers. Keep it at or below 2 KB. Replace status when it changes; never append transcripts, review coverage, repeated decisions or historical timelines. Link to authoritative plans, workshop state, runtime records or Git revisions for detail. Keep secrets and raw tokens out.

Before closing a work session, remove resolved blockers, add newly discovered blockers with their evidence level, and name the next concrete action. If the handoff grows past the limit, move authoritative detail to its proper document and condense the pointer. Review coverage belongs in workshop state or runtime review records, not here.
