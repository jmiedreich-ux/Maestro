# Maestro Agent Roles

Every agent must follow the repository-wide rules in [AGENTS.md](../../AGENTS.md), the joined project's approved engineering policy, and the exact work assignment.

## Authority order

1. Repository-wide working rules.
2. Joined-project architecture, product decisions, and engineering policy.
3. The approved work assignment.
4. The applicable role contract.
5. Any project-specific specialist overlay.

A lower level may add restrictions but cannot weaken a higher level. If two authorities conflict, the agent stops and reports the conflict.

## Roles

Registration uses the Project Architect and Decision Fidelity Reviewer under the architecture's registration rules. The Development Manager's [Execution work-planning role](maestro-development-manager.md) and the architect's bounded support responsibility are now defined. Independent implementation review, Integration Manager authority, FIFO integration and milestone promotion follow [Execution](../architecture.md#execution). Packet and integration review/correction limits and detailed completion records remain unfinished. Milestone Quality Assurance follows the architecture; retained older policies do not fill the remaining gaps. Their presence in a role file does not grant that authority through registration.

## Contract standard

Every role contract states its purpose, required inputs, authority, prohibitions, eligible work, evidence, handoff, escalation conditions, and resource restrictions. Each run records the exact role-contract revision it used.
