Previous milestones accepted and all five Registration-group packets integrated. Actual architect/reviewer selections, repository source/publication profile, exact branch and allowed credentials must be available. All external access is test-scoped.

Execute the shared setup sequence and record the exact installed candidate, plan/input hashes and resolved resources before the checks. Two small test project overviews with architecture and milestone declarations, plus a legitimate source update. Put them in separate run-owned paths/branches of the authorized QA repository. Include one genuine missing input that requires clarification. Record original source file hashes and Git commits; do not generate registration packages.

Record actual input hashes/lineage and sanitization classification under the shared data rules. Use the real public path named in each check; capture failures as well as successes. Data preparation must not insert the expected result into internal state.

## Completion and correction

Every required check must satisfy the shared PASS boundary on the same exact candidate. A required missing path, missing tool, missing observation or unavailable artifact is UNTESTED and blocks acceptance; an observed behavior defect is FAIL. Use existing correction and affected-rerun rules, not an extra QA approval round. Independent whole-milestone review remains separate and required before promotion.

This supplies real connected Registration, workspace, question, request and supervision evidence. Each claimed project-outcome criterion must be mapped to actual observations; an earlier infrastructure pass alone does not close it.

## Cleanup and reset

Retain all published package/history evidence and run refs; cancel/settle unfinished attempts before stopping the test service. Remove only disposable input copies after evidence capture; repository branch deletion remains separately authorized.

Apply the shared reset checklist. Capture evidence before cleanup, record retained/deferred resources and quarantine unsafe or uncertain environments. Do not destroy evidence or widen cleanup scope to obtain a clean result.
