## Minimum non-secret catalog information

For each provided environment: unique name, `classification: test`, non-secret variables, allowed secret names and network-dependency names. For each network dependency: exact host, protocol and allowed ports. For each secret: its public catalog name and test classification; the operator/service retains its credential locator privately. The operator must establish availability and authorization without revealing values.

For manual planning, retain an operator-supplied non-secret description with provenance and clearly label its evidence level; do not call it a service-validated `qa-catalog.json` or use an invented hash. If live Maestro is later used, its service must collect, validate and bind the actual snapshot through the defined assignment contract. Any mismatch then blocks import/use instead of silently translating a manual proposal into runtime authority.
