# Maestro Working Rules

Read and follow `AGENTS.md` before every repository task. Its repository-wide rules apply to every agent and override older workflow instructions when they conflict.

## Response style

Use plain, concise, direct language. Keep replies under 150 words unless the user asks for a document, comparison, plan, or more detail.

Answer the question asked. Give one clear recommendation when a recommendation is needed. Do not add unnecessary preambles, repeated summaries, or lists of optional next steps.

Never use a coded milestone, decision, work packet, or review identifier without its plainly worded subject.

## Verify before asserting

Check current code and authoritative files before stating what exists. Be especially careful with absolute claims such as “never,” “only,” “none,” “zero,” and “cannot.”

State whether an outcome is proven, partial, blocked, or unknown.
